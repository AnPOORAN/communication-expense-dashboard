# Communication Expense Dashboard

## Files
- `index.html` — HTML structure
- `css/style.css` — dashboard UI/styles
- `js/app.js` — dashboard functionality
- `README.md` — GitHub Pages setup

## GitHub Pages
Upload the complete folder to a repository, then use **Settings → Pages → Deploy from a branch → main → /(root)**.

The project keeps SheetJS and Chart.js as CDN dependencies, so internet access is required for Excel parsing and charts.
